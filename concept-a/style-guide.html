Accessibility rules (WCAG 2.2 AA)

  • Text contrast ≥ 4.5:1 (large text ≥ 3:1); all pairs above are pre-checked.
  • Visible 3px focus ring on every interactive element.
  • Skip-to-content link and landmark regions on every page.
  • Filters are real buttons with aria-pressed; result counts announce via aria-live.
  • No images of text: coach bios and flyers become real HTML.
  • External links (registration, volleyball) are marked with an icon and open in a new tab.
  • Mobile menu and filter sheet trap focus and close on Escape.
  • Motion respects prefers-reduced-motion.
