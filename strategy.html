Redesign concept · November 2026

Pillar Sports Academy: redesign overview

A mobile-first refresh of pillarsportsacademy.com that keeps the logo, domain, content and EZFacility registration, and makes it far easier for parents to find a program and register.

What's in this concept

01

Audit of the current site

Reviewed: pillarsportsacademy.com (home, hockey, baseball, softball, team info and staff pages) and pillarvolleyball.com/programs. The content is solid. The problems are structure, freshness and clarity.

02

Sitemap & navigation

The site is organized sport-first. A baseball parent picks Baseball once and only sees baseball: its programs, teams, pricing, coaches and contact on one page. The site remembers that choice, so Schedule and Programs open on baseball too. All-sports views stay for multi-sport families and staff.

03

Feature roadmap

Phase 1 launches the redesign with existing content and integrations. Later phases add the marketing engine.

04

Recommended tech stack

Astro + a simple Git-based CMS, hosted on Netlify, with EZFacility kept for registration and payments. It's fast, cheap to run, and the owner or staff can update dates and programs from a web form without touching code.

LayerPickWhy
FrameworkAstro (static output)Ships plain HTML/CSS by default, so pages load fast on phones. This prototype's HTML, CSS and program data port across almost 1:1; only the program finder needs JavaScript.
Content editingPages CMS (free; Decap CMS as fallback)Gives staff a simple web form for programs, dates, prices and coaches. Content is stored as files in the repo, with no database to maintain. Each edit rebuilds the site automatically.
HostingNetlify (free starter plan)Global CDN, automatic HTTPS, preview links for the owner, built-in form handling for contact and newsletter, and redirect rules for old Squarespace URLs.
Registration & paymentsEZFacility (keep)No change for staff or families. Each session button deep-links to its existing EZFacility group.
Email / newsletterMailchimp or Kit (free tier)Replaces Squarespace email signup; powers “Notify me” alerts by sport. Export and import the current subscriber list.
AnalyticsPlausible (or GA4)Privacy-friendly. Tracks clicks out to EZFacility as registrations so you can see which programs and pages convert.
Domainpillarsportsacademy.com (keep)Point DNS to Netlify at launch; 301 redirects preserve search rankings and old links.
ImagesAstro Image (AVIF/WebP)Auto-resized, lazy-loaded photos. Redraw the logo as SVG for crisp display on phones.

Running cost

Roughly $0–20/month (analytics is the main cost) once the Squarespace subscription is retired, plus the domain renewal you already pay. EZFacility fees are unchanged.

Alternative if no developer will maintain it

Webflow (CMS plan) supports the same design, and staff can edit pages visually. It costs more per month and filtering needs a plugin, but nobody touches code.
